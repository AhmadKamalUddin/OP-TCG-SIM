## 🎮 About

**OneP TCG** is a One Piece Trading Card Game pack opening simulator made for anime fans, manga fans, collectors, gamers, and anyone who loves the thrill of TCG openings.

Real One Piece products can be expensive, hard to find, or sold out. This project gives fans a way to enjoy that same excitement online while building toward a bigger all-in-one One Piece hub.

The long-term goal is to go beyond a simulator and become a full platform where users can:

- 🎴 Open packs
- 🛒 Buy packs, boxes, booster boxes, and cases
- 🕹️ Play the One Piece card game
- 🤝 Share pulls and hype moments with friends

## 🚀 Getting Started

### Requirements

To run the project locally, you need:

- **Visual Studio Code**
- **Live Server** extension by Ritwick Dey

### Install

1. Clone or download the repository:
   ```bash
   git clone YOUR_REPOSITORY_LINK_HERE
   ```

2. Open the folder in VS Code.

3. Make sure these files are present:
   ```bash
   index.html
   style.css
   script.js
   ```

### Run

1. Open `index.html`
2. Click **Go Live**
3. Launch the project in your browser
4. Start opening packs
